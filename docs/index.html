Install

The app is not signed with an Apple developer ID, so macOS quarantines it on download. Once it is in Applications:

xattr -dr com.apple.quarantine /Applications/Spectre.app

Or build it yourself — Xcode is not required:

git clone https://github.com/gaspardlebasic/spectre.git cd spectre && ./build.sh
